## 2026-07-29 - Process Fork Mitigation via Variable Caching and Pure-Bash Regex Matching
**Learning:** Repetitive external processes like `ps -ef | grep | awk` inside multiple utility functions trigger massive process fork overhead (over 150 fork calls for 25 auditing checks). Caching the raw output of the external command once in a global variable, combined with pure-Bash internal regex parsing (`[[ $var =~ regex ]]` and `BASH_REMATCH`), reduces execution overhead to a single command fork. Additionally, using `[^[:space:]]+` regex capture patterns instead of excluding commas allows robust evaluation of multi-valued Kubernetes flags (e.g. `--admission-control`), which otherwise would fail when comma-separated.
**Action:** Always identify repetitive external process invocations in shell auditing scripts and replace them with a single cached variable combined with internal shell parsing. Use unquoted asterisks (`*`) in double-bracket conditionals for wildcard substring matching on comma-separated values.
