## 2026-08-08 - [Extremely High-Impact Optimization of zephyrus.sh]
**Learning:** Process forks inside loops or repeated function executions are exceptionally slow in shell scripts. By caching process parameters (like `ps -ef | grep "[k]ube-apiserver"`) in a global variable and parsing them natively inside Bash using regex (`[[ $var =~ $pattern ]]`) and string pattern matching (`[[ $var == *glob* ]]`), we completely eliminate subprocess overhead. Furthermore, replacing `backticks` with `$(...)` inside double quotes prevents literal printing of command strings, and using `echo -en` avoids double newline layouts when sequential command execution relies on trailing newline suppression.
**Action:** Always cache command results at the start of a script when same metadata is queried repeatedly, and use native Bash regular expressions rather than piping to `grep | awk` or `sed`.
