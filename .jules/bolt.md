## 2026-07-23 - Eliminating Repetitive External Process Spawning via Argument Caching and Built-in Bash Regex
**Learning:** Repetitive spawning of external utilities (such as `ps`, `grep`, and `awk`) inside loop/audit functions in Bash scripts introduces massive fork overhead. In Zephyrus, querying the `kube-apiserver` process list in every single check resulted in 149 process forks per run. Caching the `ps` command output in a global variable (`KUBE_APISERVER_ARGS`) and parsing flags via built-in Bash regex matching (`[[ $VAR =~ REGEX ]]` and `BASH_REMATCH`) is highly performant, reduces fork overhead to just 7 processes, and eliminates subshell creation entirely.
**Action:** Always cache the results of expensive external command queries that stay constant throughout script execution, and prioritize built-in Bash pattern matching (`[[ ... ]]` and `=~`) over external process pipes (`| grep | awk`) to optimize execution speed.
