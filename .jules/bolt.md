## 2026-08-07 - Bash Global Process Caching & Native Regex Parsing
**Learning:** In auditing and security scanning shell scripts like Zephyrus, invoking external processes (`ps -ef`, `grep`, `awk`, `sed`) inside loop-like or sequentially executed independent functions creates massive fork overhead, slowing down execution significantly. By caching the external command output into a global variable exactly once at startup and parsing flags natively using Bash internal regex matching (`[[ $VAR =~ REGEX ]]`) and `printf -v` for dynamic assignments, process forks can be reduced by over 95%, making execution near-instantaneous.
**Action:** Always cache command execution outputs that are queried repeatedly, and use native Bash regex matching instead of pipes of `grep` and `awk` where performance is critical.
