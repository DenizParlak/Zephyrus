## 2026-11-01 - Process Caching in Zephyrus Kubernetes Auditor
**Learning:** In command-line audit scripts like `zephyrus.sh` that inspect process status across dozens of discrete check functions, querying process tables (`ps -ef | grep <target>`) repeatedly inside each check induces massive subshell and fork overhead (133+ execve calls, ~330ms execution). Caching the process arguments once into `KUBE_APISERVER_ARGS=$(ps -ef | grep '[k]ube-apiserver')` and piping the variable instead of spawning `ps` eliminates 27 full `ps` invocations and over half of all execve system calls, cutting execution time in half (~150ms).
**Action:** When auditing or querying daemon processes in shell scripts, scope and cache the process command line or inspection target once into an environment variable before passing it to parser pipelines.
