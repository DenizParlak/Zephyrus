## 2026-07-30 - Pure Bash Argument Extraction & Subprocess Reduction
**Learning:** Found that invoking `ps`, `grep`, and `awk` within 25 individual check functions caused extreme process fork overhead (147 forks total). By caching arguments once at startup in `KUBE_APISERVER_ARGS` and using pure Bash regex matching with `BASH_REMATCH`, process forks were reduced by ~95%, improving execution speed from 0.322s to 0.049s (85% reduction). Additionally, learned that standard `sleep` rejects custom flag arguments when trying to mock process listings using `exec -a`, but running `python3 -c "import time; time.sleep(3600)" <name> <flags>` is a robust way to mock any background process with custom flags.
**Action:** Always cache command results at script startup in Bash to avoid loops/repeated checks spawning subprocesses, and use Python for mock process listings.
